# 📱 Panel Móvil de Prospectos - La Ligua y Alrededores

Panel web optimizado para teléfonos celulares para gestionar el contacto por WhatsApp con negocios locales de **La Ligua, Valle Hermoso y Cabildo**.

### 🚀 Funcionalidades:
- **Botón Directo WhatsApp:** Abre la app de WhatsApp con el mensaje de prospección ya redactado.
- **Seguimiento de Contactos:** Casilla para marcar quién ya fue contactado (se guarda en la memoria del celular).
- **Filtros Rápidos:** Por comuna (*La Ligua, Valle Hermoso, Cabildo*) y por rubro (*Gastronomía, Cabañas, Textil, Ferretería*).
- **Buscador en tiempo real.**
- **Acceso rápido a las Demos:** Enlaces a las maquetas de Restaurante y Cabañas.
