# 📱 Panel Móvil de Prospectos — V Región (240 Locales Verificados)

Panel web interactivo y responsivo optimizado para teléfonos celulares (Android e iOS) para gestionar la prospección comercial directa por WhatsApp con **240 negocios reales verificados sin sitio web** en la V Región de Valparaíso, Chile.

🌐 **Panel en Vivo (GitHub Pages):**  
👉 **[https://pagina3.github.io/panel-prospectos/](https://pagina3.github.io/panel-prospectos/)**

---

### 🚀 Funcionalidades Principales:
- **1-Click WhatsApp:** Abre la aplicación nativa de WhatsApp en el celular con el mensaje de prospección personalizado ya redactado y el enlace a la maqueta correspondiente.
- **Seguimiento en Celular (`localStorage`):** Marca automáticamente o de forma manual quién ya fue contactado, persistiendo el progreso en el navegador de tu celular.
